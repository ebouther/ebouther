## Selected work

### Multi-tenant research platform — IEA Paris

Turning a single AWS Amplify application into a governed serverless platform across **4 AWS accounts**: automated per-tenant provisioning, **40+ Lambda services** behind AppSync, Terraform/Terragrunt infrastructure as code and ephemeral CI runners on ECS Spot. New research applications now go live **in hours instead of weeks**, with targeted deployments and lower infrastructure costs.

[Read the case study →](https://ebouther.github.io/case-studies/iea-paris)

### Rating platform for SMEs — Euler Hermes & Moody's

Backend and DevOps for a platform handling highly sensitive financial data. No developer access to production: delivery exclusively through CI across **6 environments** (dev, QA, staging, prod, ops, BCDR). Terraform on AWS, secrets in Vault, ELK search, MQTT messaging and VPC access through OpenVPN.

[Read the article →](https://www.globalbrandsmagazine.com/euler-hermes-rating-launches-new-sme-midcap-rating-service/)

### High-throughput network protocol — CNRS

Designed the RATP (Reliable Asynchronous Transport Protocol) in Ada: reliable UDP at very high throughput (10 Gb/s) with asynchronous loss handling, for particle physics data acquisition.
